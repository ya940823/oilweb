# Deployment Notes for Oil Price Web Application

## XML Files for Web Deployment

When deploying to web hosting (Azure, IIS, etc.), the XML files in `Data/` folder need to be accessible.

### Option 1: Include XML Files in Deployment (Recommended)

1. **Ensure Data folder is published**:
   - Add to `.csproj` file:
   ```xml
   <ItemGroup>
     <Content Include="Data\*.xml">
       <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
       <CopyToPublishDirectory>PreserveNewest</CopyToPublishDirectory>
     </Content>
   </ItemGroup>
   ```

2. **Verify Data folder in published output**:
   - After `dotnet publish`, check that `Data/` folder exists in output

### Option 2: Pre-load Data into Database

**This is automatically handled on first run**:
- When database is empty, `Program.cs` automatically loads data from XML files
- Data is then stored in database (SQLite or SQL Server)
- Subsequent runs use database data, no XML files needed

### For Production Deployment

1. **Before deployment**:
   - Fill XML files with your CPC oil price data
   - Run locally once to verify data loads correctly

2. **Deploy to web**:
   - Publish application with Data folder included
   - On first run, data automatically loads from XML to database
   - Database persists data, XML files only needed for updates

3. **Updating data after deployment**:
   - **Manual option**: Update XML files, click "🔄 更新資料" button on web UI
   - **Programmatic option**: Call API endpoint `POST /api/oilprices/refresh`
   - Data loads from XML files and updates database

### Configuration for Web Deployment

In `appsettings.json`, ensure:
```json
{
  "OilPriceApi": {
    "EnableApiCalls": false  // Keep false to use XML files
  },
  "ConnectionStrings": {
    "DefaultConnection": "Data Source=oilprice.db"  // SQLite for web hosting
    // OR use SQL Server for Azure: "Server=..."
  }
}
```

### Troubleshooting

**If data doesn't load on web deployment**:

1. **Check Data folder exists**: Verify `Data/*.xml` files are in published output
2. **Check file paths**: Paths are relative to application root
3. **Check database**: Ensure database file is writable on hosting environment
4. **Check logs**: Application logs will show "Loading oil prices from..." messages

**Alternative for read-only file systems**:
- Pre-load database locally with all data
- Deploy the pre-populated database file
- Disable automatic XML loading by removing startup code in `Program.cs`
